# Test Case EUCLID LAB

## 1. Tujuan Pengujian

Pengujian dilakukan untuk memastikan fitur perhitungan geometri, input pengguna, visualisasi animasi, dan narasi suara pada aplikasi EUCLID LAB berjalan sesuai dengan yang diharapkan.
